[====[INSTRUCTIONS AND INFORMATION]====]

[====[ (1) HOW TO INSTALL]====]

1. Open the "Installations" folder.

2. You will see the mod files inside. Copy and paste them into your Mental Omega folder. If you are prompted to replace any existing files, click Replace.

3. Open Mental Omega and enjoy the new Spook voice lines!

[====[ (2) INFORMATION]====]

This is a Mental Omega mod created by PromasterYTJava. It replaces all default Spook sound effects with the voice of the Mental Omega player known as Spook, a well-known individual in the Mental Omega community, recognized for his behavior and appearances in Glioper’s livestreams and Darkraiah’s streams.

This mod was inspired by the fact that Spook’s name matches the Epsilon infantry unit codenamed "Spook" That similarity gave me the idea to replace the unit’s voice lines with Spook’s actual voice.

[====[ (3) FOLDER OVERVIEW]====]
There are three folders included in this installation. Below is an explanation of each:

1. Images Folder
This folder contains all icon images for the in-game Infantry Spook unit. One version is optimized for in-game use. One version is an HD version for those who prefer higher resolution. Inside the Images folder, there is another folder called "Editable." This folder contains an editable version of the Spook icon named "spook.pdn".

To edit this file, you may need to install a third-party program called paint.NET, since the .pdn file extension is native to paint.NET. I am not certain whether other photo editing software, such as Photoshop, supports the .pdn format. Therefore, I highly recommend using paint.NET to access and edit the file.

You can download paint.NET here:
https://www.getpaint.net/

2. Installation Folder
This folder contains all the necessary installation files. Please refer to the Installation Guide above for instructions on how to install the mod.

3. SpookSounds Folder
This folder contains all the sound files used in-game. The sounds are organized into their respective folders.
For example, the "Attack" folder contains all of Spook’s attack voice lines.
